### Почему cmdline доступен всем, а environ нет?
Файл cmdline (командная строка запуска) по умолчанию открыт для чтения всем пользователям системы. Это сделано специально, чтобы администратор и сами пользователи могли видеть, какие программы сейчас запущены и с какими параметрами. Файл environ (переменные окружения) защищен на уровне ядра операционной системы по UID (идентификатору пользователя). В переменных окружения часто хранятся секретные ключи, пароли и токены доступа, поэтому прочитать их может только владелец процесса или суперпользователь.

### Правила передачи пароля
Передавать пароль аргументом в командной строке нельзя, так как он становится виден любому пользователю сервера через обычную команду ps. Правильно передавать секретные данные так:

- Через переменные окружения.
- Через отдельный конфигурационный файл, на который установлены строгие права доступа (например, 600 — чтение и запись только для владельца).
- Через интерактивный ввод (когда программа при запуске просит пользователя ввести пароль с клавиатуры).
